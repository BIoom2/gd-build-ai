# Random Set

Adds a **Random Set** button to the icon kit (garage) menu in Geometry Dash. Click it to open a popup that generates a complete random icon set across every gamemode (cube, ship, ball, UFO, wave, robot, spider, swing) together with random primary, secondary and (optional) glow colors.

## Features
- One-click random icon set covering all 8 gamemodes
- Auto-picks color 1, color 2 and an optional glow color
- **Next** button to roll another set without applying
- **Set** button to apply the displayed set to your profile
- Works correctly with any installed texture pack — all previews are drawn with the game's own icon sprite frames, so whatever texture pack you have installed is shown both in the preview and after applying
